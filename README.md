# ITIS 3135 Coursework _(3135-website)_

A historical web-development coursework site built with HTML, CSS, and JavaScript.

## Background

This repository contains work from ITIS 3135. I keep it public as a record of earlier front-end coursework rather than as a current flagship project.

## Install

```bash
git clone https://github.com/ameliaeckard/3135-website.git
cd 3135-website
python -m http.server 8000
```

## Usage

Open `http://localhost:8000`. Course-specific pages live under `itis3135/`.
